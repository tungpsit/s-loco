# S-Loco Architecture Document

> **Project**: S-Loco — a local services marketplace for Sam Son beach, Vietnam. Tourists browse and purchase service vouchers from local vendors; vendors redeem vouchers; an admin dashboard manages the platform; a settlement system handles vendor payouts.
>
> **Stack**: Bun + Hono (API) · Next.js 16 (Admin) · Expo/React Native (Mobile + Vendor apps) · PostgreSQL via Drizzle ORM · Redis for rate limiting · Docker Compose for local infra.
